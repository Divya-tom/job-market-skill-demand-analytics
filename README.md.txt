# 📊 Job Market & Skill Demand Analytics Dashboard

## 📌 Project Overview

This project analyzes job market trends using a LinkedIn Job Postings dataset.  
The dashboard was built in **Power BI** to uncover insights related to skill demand, salary trends, geographic hiring patterns, and emerging technologies.

The dataset contains approximately 99,000 job postings.

---

## 🎯 Key Insights

### 1️⃣ Most Demanded Skills
- Excel is the most frequently required skill.
- SQL and AWS follow closely.
- Data-related tools dominate the job market.

### 2️⃣ Salary Trends
- Median salary peaked in March 2024.
- Salary analysis is based on 33% of postings where compensation data was available.
- Cloud and analytics skills command higher median salaries.

### 3️⃣ City-wise Job Demand
- United States has the highest overall job concentration.
- Major hiring hubs include New York, Chicago, and Houston.

### 4️⃣ Emerging Technologies
- SQL is currently the fastest growing skill.
- Tableau and Power BI show increasing demand.
- Growth calculated using last 30 days vs previous 30 days comparison.

---

 📈 Dashboard Features

- 📊 Job Posting Trend (2023–2024)
- 💰 Salary Trend (Median)
- 🚀 Emerging Skills Growth %
- 📍 Top Hiring Cities
- 💼 Work Type Distribution
- 🏠 Remote Opportunity Percentage
- 💵 Salary by Skill & City

---

## 🛠 Tools & Technologies Used

- Power BI
- DAX
- Power Query
- Kaggle LinkedIn Job Postings Dataset

---

 ⚠ Data Limitation

Salary analysis is based on 33% of postings where salary data was available.  
Results represent indicative market trends rather than full population averages.
